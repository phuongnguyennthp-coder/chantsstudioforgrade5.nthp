# chantsstudioforgrade5

Ứng dụng phòng thu âm nhạc & bài hát Chants tiếng Anh dành cho học sinh Lớp 5 (Grade 5 Elementary English Chants & Music Studio).

## Các tính năng chính (Core Features):
1. **Upload video cho học sinh xem (Watch Song Videos)**: Hỗ trợ xem video bài hát mẫu, tải lên file video MP4/WebM hoặc dán link YouTube/Video trực tiếp trên giao diện chính và trong Teacher Studio.
2. **Beat nhạc theo video bài hát để thực hành (Backing Beat)**: Hệ thống beat nhạc nhịp nhàng (trống kick/clap, piano chords) đồng bộ BPM, hỗ trợ tùy chỉnh tốc độ (-5/+5 BPM) và tải lên file beat nhạc riêng.
3. **Micro thu lại sản phẩm học sinh hát (Microphone Voice Recording)**: Bộ đếm 3 giây trước khi thu âm, sóng âm thanh nhảy theo giọng hát thời gian thực, nút nghe lại, thu âm lại và tải file ghi âm về máy.
4. **Nút nộp bài (Submit Chant)**: Nút "NỘP BÀI / SUBMIT CHANT" kèm trạng thái kiểm tra ghi âm và lưu lịch sử bài tập.
5. **AI Buddy phản hồi (RoboBuddy AI Feedback)**: Mascot Robot AI vui nhộn chấm điểm, xếp hạng sao (3-5 sao), tặng huy hiệu âm nhạc, gửi lời nhận xét và mẹo luyện tập bằng tiếng Anh cùng giải thích tiếng Việt, kèm âm thanh ting-ting và pháo hoa giấy.
6. **Cài đặt API Key & Model**: Hỗ trợ người dùng tự nhập Google Gemini API key từ Google AI Studio và chọn model trực tiếp trên thanh Header.

## Chạy cục bộ (Run Locally):
1. Cài đặt thư viện: `npm install`
2. Khởi chạy: `npm run dev`
